# 最新行情优先，统计不阻塞行情

本轮按用户明确的新要求调整上一轮缓存优先策略。不是仅确认需求，已修改源码并重新打包。

## 最终行为

- 启动、重新打开指数、选择目录时，在保留已有可用画面的同时尝试联网取得最新指数；即使有通达信目录、已有缓存、缺少最新日期统计，也不会因此跳过联网尝试。
- 通达信更新检测继续工作；本地和在线指数按日期合并，较旧响应不能删除已取得的较新日期。统计不参与指数是否更新的判断。
- 最新日期统计不存在时显示“统计待补齐”，不会拿旧日期数字充当新日期统计，也不会退回旧行情以迁就统计。
- 后台统计完成后直接更新可见标签，无需移动 K 线。已存在的目标日期统计不重复请求；无文件变化时不反复重建或重绘。
- 网络失败保留已有行情。这里承诺的是尝试取得最新行情，不保证离线或服务不可用时能得到新数据。
- 已恢复/正在进行的模拟训练保留原引擎和账户，后台更新指数缓存，不把模拟强行跳到最新交易日。

## 文件

- `stock_simulator/app.py`：取消缓存/本地目录阻断在线指数更新的条件；覆盖无数据首次显示、较旧结果保护、目录选择入口、独立统计占位和显示。
- `stock_simulator/market_sync.py`：本地统计同步写入指数缓存时保留已存在的较新日期；避免回调重复写缓存引发反复重建。
- `stock_simulator/index_data.py`：指数缓存使用独立临时文件，避免本地后台更新和在线回调共用同一个临时文件。
- `tests/test_market_sync.py`：按新需求更新旧策略测试，增加无统计在线更新、旧本地/网络结果晚到、空窗口、失败保留、训练保护和统计后到自动显示验证。
