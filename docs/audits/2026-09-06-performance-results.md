# 性能优化结果

## 已实施

- BOLL 改为滚动均值/方差计算，同一数据及参数下复用结果，单帧不重复计算。
- GMA、成交量均线与日期索引缓存；仅遍历画面可见的 K 线来绘制曲线；复用曲线横坐标。
- 缓存校验包含完整不可变 K 线快照与开收盘揭示状态，中间数据替换、切换股票/参数或可见状态会重新计算。最多保留 32 组派生结果，数据改变时清空。
- 平移、缩放不再安排未变化账户的保存；业务操作仍保存。成绩列表未变化时复用行控件，变化时重建。
- 空通达信目录不再转换成当前目录后递归扫描；启动时复用已解析的数据目录。
- 使用现有目录版打包配置生成最新 EXE，包含前一轮 Bug 修复。未覆盖旧程序。

## 同机对比

Python 3.10.18、PySide6 离屏绘制，1 万根合成历史 K 线，可见 120 根，画布 1100×750，默认两副图。完整控件绘制 12 次，常态为第 3—12 次中位数。

| 场景 | 修改前 | 修改后 | 耗时下降 |
| --- | ---: | ---: | ---: |
| 普通图表常态重绘 | 20.158 ms | 10.279 ms | 49% |
| BOLL 常态重绘 | 145.854 ms | 12.162 ms | 92% |
| GMA 常态重绘 | 74.572 ms | 13.835 ms | 81% |
| 空配置窗口初始化到显示，中位数 | 142.890 ms | 125.650 ms | 12% |

- 首次 BOLL 绘制：143.030 → 34.983 ms；首次 GMA 绘制：74.008 → 50.604 ms。首次计算仍比缓存后的绘制慢。
- 启动指标包含窗口构造、show 与事件处理，构造阶段启用 cProfile；每个版本在独立进程测 5 次窗口创建。已移除前一窗口的事件过滤器，避免累积干扰。
- 上述启动数字不包含操作系统启动进程、Python/Qt 导入、真实通达信扫描与联网更新；不等于用户点击 EXE 到完整行情可用的总时间。
- 初始临时基线与本机源码的导入缓存状态不同，因此不将导入耗时差异作为优化收益。没有做清空系统磁盘缓存的冷启动实验。
- 目录版不需要像单文件版一样每次解压内置依赖，启动机制参见 [PyInstaller 官方说明](https://pyinstaller.org/en/stable/operating-mode.html)。没有构建同源码单文件版进行 EXE 对照，因此不声称打包方式带来具体百分比提升。
- 不承诺所有机器及所有数据下零延迟；多副图全部打开、显示大量 K 线、慢磁盘与网络仍影响体验。
