# 通达信更新与上证统计同步修复

## 问题与修改

本机 D:\TDX 的指数和股票日K已有 2026-09-04 数据，原统计缓存仅到 2026-09-03。原窗口按目录记住“曾请求统计”，同一目录更新数据后仍会跳过；缓存统计被清空而文件偏移还在时，也可能跳过历史重建。

- `stock_simulator/app.py`：导入目录、启动和后台每 5 秒检查共用同一个更新入口。后台任务去重，完成后允许检查新的变化；统计未变时不重绘、不保存训练存档。训练引擎保留，旧目录的回调被丢弃。已选择本地数据时，在线指数/统计回调不能覆盖本地结果。
- `stock_simulator/market_sync.py`：后台检查文件路径、大小和纳秒修改时间及两个缓存文件。指纹未变直接返回；变化或缓存缺失时同步指数和市场统计。兼容 sh999999 与 sh000001 两种上证文件。
- `stock_simulator/market_stats.py`：统计内容校验和用于识别清空、缺行等缓存变化；首次升级会重建旧缓存。文件记录不完整或计算期间仍在下载时不提交混合统计，下一次检查重试。
- `tests/test_market_sync.py`：覆盖同目录追加、同大小改写、缓存删除/清空、备用指数文件、下载中途改写、旧回调、训练保护，以及数据到界面标签的完整更新过程。

额外修复：首次打开没有行情引擎时，默认训练标记曾阻止后台结果打开指数；现在仅保护已经存在的训练引擎，从空白窗口导入也能显示指数和统计。

这里的 5 秒是发现更新的检查间隔，不是统计全部完成的承诺。计算完成后停止计算和刷新，仅保留后台文件检查。数据不完整或文件无法读取时不会伪造统计。
