# 新用户目录为空，统计由用户选择的数据源生成

## 原因与修复

前一轮为满足首次启动最新行情，加入了自动扫描常见通达信安装目录并保存结果的逻辑；因此即便便携包设置本身为空，也会在作者电脑上自动填入 D:\TDX。这与用户本轮明确要求不符，现已取消。已有用户自己保存的目录仍会记住；新用户使用干净便携包时目录为空。

本地统计的另一个问题是切换/初始化目录时清空了同目录的有效缓存，并且统一“统计待补齐”掩盖了计算和失败状态。现改为立即加载匹配所选目录的有效缓存，在后台检查/更新；没有缓存时显示“正在统计”，失败时显示重试提示及详细原因，数据比当前指数旧时显示本地统计截止日期。完成后自动更新标签和完成提示，无需移动 K 线。

## 最终行为

- 首次启动不扫描、不自动填写任何人的通达信目录。
- 未选择目录时，不生成本地统计、不请求在线全市场统计；统计栏提示“请选择通达信目录”。仅在输入框里打字也不会自动启动统计。
- 指数行情仍独立尝试联网更新，不受统计缺失影响。
- 用户选择有效目录后启动本地统计，记住该目录，后续检测文件变化/缓存缺失时更新。
- 新配置不再从安装包复制全市场统计缓存；打包时排除包含来源路径的原统计资源。便携包始终采用目录为空的默认设置，不复制作者配置和记录。
