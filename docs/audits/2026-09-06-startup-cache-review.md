# 启动后统计先显示、后消失的根因修复

## 复现和根因

用户补充完整顺序：打开时显示缓存，没有设置通达信目录，随后统计消失，左右移动 K 线又出现。运行 EXE 哈希确认与上轮版本一致。

检查发现便携版内置的指数和市场统计都截至 2026-08-21。没有通达信目录时，旧启动流程先显示这一配套缓存，接着仍发起在线指数更新。指数能更新到 2026-09-04，而在线市场统计可能失败；当前日期随指数推进后，统计字典中没有该日期，于是显示“市场统计暂未更新”。向左移动到有缓存的日期，又能看到统计。

此流程已经用实际方法调用稳定复现，逐阶段日期和标签见 `2026-09-06-startup-market-reproduction.json`：08-21 有统计 → 在线指数推进到 09-04 后无统计 → 左移回 08-21 后又有统计。

前两轮把症状主要归因于绘图刷新，未覆盖“无通达信目录的完整启动与在线更新”过程。这次修复的是后续数据源更新改变查看日期的问题，而不是继续追加绘图调用。

## 修改

`stock_simulator/app.py`：

- 已有可用指数缓存时，不在启动和再次打开指数时单独联网推进指数日期；随后由本地通达信同步流程负责更新。
- 已有目标日期统计时，不再重复请求在线统计。
- 在线请求发出后，如果缓存或通达信数据已经就位，晚到的在线指数结果不再覆盖当前行情。
- 数据确实不存在时，保留原有联网补齐入口；没有把旧日期统计冒充新日期。

`tests/test_market_sync.py`：增加无目录启动、在线指数成功但统计失败、迟到在线结果覆盖缓存的回归验证。修复前失败，修复后全部 69 项测试通过。
