# Excel导出修改记录

仅更新源码；未构建、导出或替换独立便携版、普通便携版或现有EXE。源码运行需要 requirements.txt 中的 PySide6 和 openpyxl，当前开发环境已有相应版本。

## 功能

- 文件菜单和成绩浮窗默认导出带图表的 Excel；CSV 导出保留为文件菜单单独入口。
- 总览页：资金曲线为蓝色（金额左轴），回撤曲线为红色（比例右轴），置于同一张图。回撤以此前日末账户最高资产（含期初资金）为基准。
- 每段回撤在最深处标金额与比例；为了长历史可读性，只标比例最大的8段，所有每日回撤值完整保留。
- 同时提供累计收益率图。
- 工作表包括统计概览、股票轮次、交易分段、成交明细、原始统计、每日资产、资产原始记录。原始统计保留旧CSV全部列和所有行。
- 每日取最后收盘观察；未收盘日取最后开盘观察。按日期排序，不补造缺失日期，不把相互重叠的不同轮次拼成一条曲线。多轮在各自的曲线页展示。
- 表格有冻结表头、筛选、交替行色和金额/比例格式。图表缓存包含全部数值与日期，以兼容预览器及表格软件。
- 失败有提示；Excel先写同目录临时文件，再原子替换；导出入口自动避免同名文件。
